# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` - главная страница;
- `catalog.html` - каталог товаров;
- `product.html` - страница товара «Клавиатура»: фото, описание, цена и таблица характеристик;
- `product-mouse.html`, `product-headset.html`, `product-webcam.html` - страницы остальных товаров с тем же устройством;
- `order.html` - страница оформления заявки;
- `contacts.html` - контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` - модальное окно заявки и проверка полей формы;
- `images/` - фото товаров: `keyboard.jpg`, `mouse.jpg`, `headset.jpg`, `webcam.jpg` (1000×750) для страниц товаров и уменьшенные копии `*-small.jpg` (480×360) для карточек каталога. Источник - Wikimedia Commons, общественное достояние и CC0;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Текущий статус

Создан многостраничный учебный интернет-магазин ShopProject:

- единая шапка, меню и подвал на пяти страницах;
- каталог товаров с категориями и боковым блоком фильтров;
- отдельная страница для каждого товара: фото, описание, цена, наличие, кнопка заявки и таблица характеристик;
- страница заявки с формой оформления заказа;
- страница контактов со ссылкой на форму заявки и блоком частых вопросов;
- хлебные крошки на всех страницах, кроме главной;
- уникальные `title` и `meta description` для каждой страницы;
- якорные ссылки с плавной прокруткой и подсветкой через `:target`;
- hero-блок со ссылкой на товары;
- список преимуществ проекта;
- четыре карточки компьютерных аксессуаров с категориями и учебными ценами, одного товара нет в наличии;
- бейджи «Новинка», «Скидка» и «Нет в наличии» на верхней рамке карточек;
- кнопка «Наверх», закреплённая в правом нижнем углу экрана;
- дополнительный информационный блок и подвал с данными автора.

Использованы семантические элементы `header`, `nav`, `main`, `section`,
`article`, `aside`, `footer`. Оформление вынесено в `css/style.css`.
Добавлены минимальный сброс стилей, `box-sizing: border-box` и подсветка
фокуса при навигации с клавиатуры. Шапка, меню и кнопки внутри формы используют Flexbox.
Карточки товаров расположены в CSS Grid с автоматическим подбором числа колонок.

## Реализованные элементы интерфейса

- Кнопки «Заказать» в карточках товаров. У товара, которого нет в наличии, кнопка отключена атрибутом `disabled`.
- Модальное окно `dialog` с формой: выбранный товар записывается в скрытое поле и показывается в окне.
- Поля формы: имя, e-mail, телефон, дата связи, тема, комментарий и согласие. На странице заявки вместо темы - выбор товара.
- HTML-ограничения `required`, `minlength`, `type="email"` и `pattern`.
- Проверка каждого поля через `checkValidity()`: ошибочное поле подсвечивается через `aria-invalid`, под ним появляется текст ошибки, фокус переходит на первое такое поле.
- Закрытие кнопкой «Закрыть», клавишей Escape и кликом по затемнённому фону, сброс формы после успешной проверки.
- Пока окно открыто, страница под ним не прокручивается: `body:has(.order-dialog[open])` получает `overflow: hidden`. `scrollbar-gutter: stable` у `html` не даёт странице сдвинуться, когда пропадает полоса прокрутки.
- После успешной проверки в модальном окне вместо формы появляется сообщение «Заявка отправлена!», на странице заявки под формой - «Форма успешно отправлена!».

Отправка учебная: сервер не подключён, данные никуда не передаются и не сохраняются.
`novalidate` отключает автоматическую проверку перед отправкой, чтобы JavaScript
мог пометить ошибочные поля. Реальную отправку отменяет `event.preventDefault()`.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`: цвета `--color-*`, отступы `--space-*`, скругления `--radius-*`, ширина контейнера `--container-width`;
- единая шкала отступов: 4, 8, 16, 24 и 32px;
- состояния `:hover`, `:active`, `:focus`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`: переменные, базовые стили, общие элементы интерфейса, компоненты страницы, форма и модальное окно.

## Использование Flexbox и Grid

- Flexbox выравнивает шапку, основное меню и кнопки формы заявки.
- Пункты меню имеют увеличенную область клика и фон при наведении.
- Карточки товаров используют Flexbox с направлением `column` и промежутками через `gap`; цены и кнопки выровнены по низу карточек.
- `.products-grid` задаёт сетку карточек на главной и в каталоге.
- `.catalog-layout` использует колонки `260px 1fr` и именованные области `filters` и `products`.
- `.catalog-layout__filters` занимает область `filters`, `.catalog-layout__products` - область `products`.
- `.filters-form` размещает группы категории и цены через Grid с `gap`.
- `.product-details` - Grid с `auto-fit`: фото и описание товара в две колонки, таблица характеристик на всю ширину под ними. На узком экране описание само уходит под фото.
- `.product-details__info` выстраивает категорию, название, цену и кнопку Flexbox-колонкой.

Фильтры - учебная HTML-форма: кнопка «Применить» отправляет параметры методом GET,
но состав товаров не меняется. Логика фильтрации и адаптивная раскладка каталога
по медиазапросам в этой практике не реализуются.

- `advantages-list` - список преимуществ;
- `products-grid` - сетка товаров;
- `product-card` - карточка товара;
- `product-details` - страница товара;
- `product-table` - таблица характеристик;
- `catalog-layout` - структура страницы каталога;
- `catalog-filters` - фильтры каталога;
- `filters-form` - форма фильтров;

Классы названы по методологии БЭМ:

- блок - самостоятельный компонент: `.product-card`;
- элемент - часть блока, отделяется `__`: `.product-card__title`;
- модификатор - вариант блока или элемента, отделяется `--`: `.product-card--out-of-stock`, `.site-nav__link--active`.

остались только в базовых стилях: сброс, отступы `main`, ссылки и фокус.

БЭМ-миксы - на одном элементе классы нескольких блоков:

- `button button--primary product-card__button` - общий вид кнопки и её место в карточке;
- `catalog-filters catalog-layout__filters` - оформление фильтров и их область в сетке каталога;
- `product-table product-details__specs` - оформление таблицы и её место на странице товара;
- `button button--primary to-top` - вид кнопки и положение «Наверх» на экране.

## Позиционирование элементов

| Свойство | Где используется | Что делает |
| --- | --- | --- |
| `position: relative` | `.product-card` | карточка остаётся на месте, но становится точкой отсчёта для бейджа |
| `position: absolute` | `.product-card__badge` | бейдж убран из потока и посажен на верхнюю рамку карточки через `top` и `right` от карточки |
| `position: fixed` | `.to-top` | кнопка «Наверх» привязана к окну браузера и не прокручивается вместе со страницей |
| `position: sticky` | `.site-header` | шапка с меню прокручивается до верхнего края окна и остаётся там (на экранах от 1200px) |

У бейджа отрицательный `top`, поэтому он выходит за край карточки и не наезжает
на заголовок. У кнопки «Наверх» `z-index: 10`, чтобы она была над карточками.

Шапка с `sticky`, в отличие от `fixed`, остаётся в потоке страницы, поэтому
содержимое под ней не прячется. `z-index: 20` держит её над карточками и кнопкой «Наверх».
На экранах уже 1200px меню переносится на несколько строк и заняло бы до трети
экрана, поэтому там шапка прокручивается вместе со страницей. `scroll-padding-top`
у `html` останавливает раздел после перехода по якорю под шапкой, а не за ней.
У шапки нет `id="top"`: ссылка `#top` без такого элемента по стандарту HTML
прокручивает в начало страницы, а к закреплённой шапке браузер прокручивать не стал бы.

## Самостоятельные доработки

Сверх обязательных требований КР №1 в проекте сделаны четыре доработки.

1. **Несколько вариантов карточек через БЭМ-модификаторы.** Кроме `product-card--out-of-stock`
   добавлены `product-card--new` (бейдж «Новинка») и `product-card--discount` (бейдж «Скидка»,
   красная цена и зачёркнутая старая цена в `<s>`). Один класс на карточке меняет сразу
   бейдж и цену, а разметка карточки остаётся общей для всех товаров.
2. **Блок частых вопросов** на странице контактов. Сделан на `details` и `summary`:
   ответ раскрывается без JavaScript, вопросы доступны с клавиатуры, а скринридер
   понимает, что это раскрывающийся элемент.
3. **Улучшенное модальное окно.** В окне видно, какой товар заказывают. После отправки
   сообщение об успехе появляется в самом окне вместо формы, а не под подвалом страницы,
   где его не видно. Окно закрывается кликом по затемнённому фону и при закрытии
   сбрасывает старые ошибки.
4. **Улучшенная доступность формы.** Обязательные поля отмечены звёздочкой, над полями
   есть пояснение к ней. Ошибки выводятся текстом под полем и связаны с ним через
   `aria-describedby`, поэтому скринридер читает их вместе с названием поля. Фокус
   переходит на первое поле с ошибкой, ошибка исчезает сразу после исправления,
   сообщение об успехе получает фокус. У телефона добавлены `autocomplete="tel"`
   и связь с подсказкой о формате.

## Как открыть и проверить

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.

- Откройте каталог на широком экране: фильтры должны находиться слева, товары - справа. В DevTools проверьте `grid-template-areas`, `grid-area` и `gap`.
- Проверьте категории и поля цены: значения меньше нуля не проходят встроенную проверку. После нажатия «Применить» параметры появляются в URL, список товаров остаётся прежним.
- Проверьте фон ссылок меню при наведении и выравнивание кнопок карточек с разной длиной текста.
- На каждой странице проверьте ссылки меню «Главная», «Каталог», «Заявка» и «Контакты»: пункт текущей страницы выделен фоном.
- С каждой страницы перейдите к разделам главной: «Преимущества», «Популярные товары», «Обратная связь». Цель якоря выделяется пунктирной рамкой.
- На страницах каталога, товара, заявки и контактов проверьте хлебные крошки.
- В каталоге нажмите «Подробнее», на главной - название товара: откроется страница именно этого товара. У веб-камеры, которой нет в наличии, вместо заявки отключённая кнопка, у наушников цена со скидкой.
- В каталоге у каждой карточки есть фото товара: уменьшенная копия 480×360 с `loading="lazy"`, пропорция 4:3 держится через `aspect-ratio` и `object-fit`.
- На странице товара проверьте таблицу характеристик: подпись `caption`, строка заголовков в `thead`, данные в `tbody`.
- Кнопка «Оформить заявку» на странице товара и на странице контактов открывает страницу заявки.
- На странице заявки отправьте пустую форму: обязательные поля подсветятся, под каждым появится текст ошибки, фокус встанет на первое поле с ошибкой. Исправьте поле - его ошибка сразу исчезнет. Заполните поля и выберите товар - под формой появится сообщение об отправке.
- Сравните карточки товаров: «Новинка» - синий бейдж; «Скидка» - красный бейдж, красная цена и зачёркнутая старая; «Нет в наличии» - серый фон и отключённая кнопка. Вид задают модификаторы `product-card--new`, `product-card--discount`, `product-card--out-of-stock`.
- На странице контактов откройте частые вопросы щелчком или с клавиатуры (Tab, затем Enter или пробел). У раскрытого вопроса синяя рамка.
- Проверьте уникальные заголовки вкладок и `meta description` в исходном коде всех страниц.

- Проверьте, что видны шапка, первый экран, преимущества, четыре товара, aside и подвал.
- Нажмите «Перейти к товарам» и ссылки меню: они должны вести к нужным разделам.
- Проверьте фон, отступы и рамки карточек - это признаки подключения CSS.
- Перемещайтесь клавишей Tab: у ссылок, кнопок и полей формы должна появляться синяя рамка фокуса.
- Наведите курсор на ссылки, кнопки, карточки и поля формы: меняется цвет, фон или рамка.
- Зажмите любую кнопку мышью: в момент нажатия она немного уменьшается.
- Щёлкните по полю формы: в фокусе у него появляется светло-голубой фон.
- Наведите курсор на кнопку «Нет в наличии»: она бледнее остальных, курсор `not-allowed`, нажатие ничего не делает.
- Убедитесь, что вокруг страницы нет стандартного внешнего отступа браузера.
- Нажмите «Заказать» у каждого товара в наличии: название товара видно в окне под заголовком,
  а в DevTools - в значении скрытого поля `selected-product`.
- Отправьте пустую форму: обязательные поля должны подсветиться, под ними появятся тексты ошибок, окно остаётся открытым.
- Проверьте имя из одной буквы, e-mail без `@` и телефон без нужного форматирования.
- Введите имя от двух символов, `student@example.com`, `+7 (900) 000-00-00`,
  выберите тему и поставьте согласие. Дата и комментарий необязательны.
- После отправки окно остаётся открытым: вместо формы появляется сообщение
  «Заявка отправлена!» и кнопка «Готово». При следующем открытии форма снова пустая.
- Проверьте закрытие кнопкой «Закрыть», клавишей Escape и кликом по затемнённому фону вокруг окна.
- Откройте форму и покрутите колесо мыши: страница под окном стоит на месте. После закрытия прокрутка снова работает.
- Прокрутите страницу: кнопка «Наверх» остаётся в правом нижнем углу экрана, по нажатию страница возвращается в начало.
- На широком экране (от 1200px) прокрутите любую страницу: шапка с меню остаётся у верхнего края окна. Переход по пункту «Популярные товары» не прячет заголовок раздела под шапкой.
- В DevTools у карточки «Веб-камера» снимите галочку `position: relative`: бейдж улетит в правый верхний угол страницы, потому что точкой отсчёта станет сама страница.
- В DevTools проверьте классы карточки: `product-card__title`, `product-card__price`.

## Постановка контрольной работы №1

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

В рамках контрольной работы необходимо разработать многостраничный
HTML/CSS-сайт интернет-магазина или каталога услуг.

Проект должен включать:

- главную страницу;
- страницу каталога;
- страницу карточки товара или услуги;
- страницу оформления заявки;
- страницу контактов;
- семантическую HTML-разметку;
- внешний CSS-файл;
- базовую навигацию;

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина:
все перечисленные страницы и элементы выполнены.

## История выполнения

- Практическая работа 1: создан Git-репозиторий, опубликован проект на GitHub Pages.
- Практическая работа 2: создан HTML-каркас стартовой страницы и выполнено базовое CSS-оформление.
- Практическая работа 3: добавлена форма заявки, модальное окно и базовая валидация.
- Практическая работа 4: добавлены CSS-переменные, состояния интерфейса и упорядочена структура стилей.
- Практическая работа 5: создана многостраничная структура сайта, добавлены единая навигация, якорные ссылки, хлебные крошки и метаданные страниц.
- Практическая работа 6: доработаны Flexbox-навигация и карточки, добавлена Grid-раскладка каталога с фильтрами и списком товаров.
- Практическая работа 7: выполнен рефакторинг CSS-стилей по методологии БЭМ.
- Практическая работа 8: добавлены страницы товара и заявки, категории каталога и таблица характеристик, выполнены самостоятельные доработки, проект подготовлен к сдаче КР №1.
- Контрольная работа №1: классы переведены на БЭМ, добавлено позиционирование `relative`, `absolute`, `fixed`.
