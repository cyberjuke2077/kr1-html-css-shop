## Текущий статус

Создана стартовая страница учебного интернет-магазина ShopProject:

- шапка и меню с переходами к разделам;
- hero-блок со ссылкой на товары;
- список преимуществ проекта;
- три карточки компьютерных аксессуаров с учебными ценами;
- дополнительный информационный блок и подвал с данными автора.

Использованы семантические элементы `header`, `nav`, `main`, `section`,
`article`, `aside`, `footer`. Оформление вынесено в `css/style.css`.
Добавлены минимальный сброс стилей, `box-sizing: border-box` и подсветка
фокуса при навигации с клавиатуры. Карточки расположены последовательно,
без Flexbox и Grid. Flexbox используется только для кнопок внутри формы.

## Реализованные элементы интерфейса

- Кнопки «Заказать» в каждой карточке товара.
- Модальное окно `dialog` с формой и скрытым полем выбранного товара.
- Поля формы: имя, e-mail, телефон, дата связи, тема, комментарий и согласие.
- HTML-ограничения `required`, `minlength`, `type="email"` и `pattern`.
- Проверка через `checkValidity()` и `reportValidity()`, подсветка ошибок через `aria-invalid`.
- Закрытие кнопкой и клавишей Escape, сброс формы после успешной проверки.
- Сообщение «Форма успешно отправлена!» после успешной проверки.

Отправка учебная: сервер не подключён, данные никуда не передаются и не сохраняются.
`novalidate` отключает автоматическую проверку перед отправкой, чтобы JavaScript
мог пометить ошибочные поля. Реальную отправку отменяет `event.preventDefault()`.

## Как открыть и проверить

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.

- Проверьте, что видны шапка, первый экран, преимущества, три товара, aside и подвал.
- Нажмите «Перейти к товарам» и ссылки меню: они должны вести к нужным разделам.
- Проверьте фон, отступы и рамки карточек - это признаки подключения CSS.
- Перемещайтесь клавишей Tab: у ссылок должен появляться видимый фокус.
- Убедитесь, что вокруг страницы нет стандартного внешнего отступа браузера.
- Нажмите «Заказать» у каждого товара и проверьте в DevTools значение
  скрытого поля `selected-product`.
- Отправьте пустую форму: обязательные поля должны подсветиться, окно остаётся открытым.
- Проверьте имя из одной буквы, e-mail без `@` и телефон без нужного форматирования.
- Введите имя от двух символов, `student@example.com`, `+7 (900) 000-00-00`,
  выберите тему и поставьте согласие. Дата и комментарий необязательны.
- После отправки окно закрывается, поля очищаются. Под подвалом страницы
  появляется сообщение «Форма успешно отправлена!», как в примере методички.
- Проверьте закрытие кнопкой «Закрыть» и клавишей Escape.
